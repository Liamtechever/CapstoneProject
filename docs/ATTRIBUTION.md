# Attribution and licensing

This repository is a capstone project published under the Liamtechever GitHub account. Its contribution is the application code and integration of existing services and libraries. Repository history is retained; this documentation does not claim sole authorship or infer individual contributions from commits.

The cleanup refactors and tests the existing prototype with assistance from OpenAI Codex. It does not represent new model training or independently developed speech/vision models.

Major dependencies and services include Django, Ollama, OpenAI's SDK and hosted models, OpenAI Whisper, PyTorch, Coqui TTS (via the maintained coqui-tts package), librosa, OpenCV, sounddevice, soundfile, and SQLite. Their code, pretrained weights, names, licenses, and service terms remain those of their respective maintainers/providers.

The model names and most heuristic registry values are inherited from the original capstone. They should not be described as independently benchmarked. The unknown 671B memory estimate and inconsistent vision cost score were corrected during cleanup.

Project licensing is intentionally undecided at the repository owner's request. No LICENSE file has been added. Do not treat public visibility as a blanket permission to redistribute this project's code. Add specific collaborator, tutorial, or other source credits when their provenance is confirmed.
